# i18n system — removed

The config-driven internationalization system was removed in two steps and this page is the record;
the full pre-removal documentation is in this page's git history.

1. **2026-07-17** (commit `56f86ac` "remve") — `pnpm remove-i18n` collapsed the project from `en`/`fr`
   to single `en`: the fr config/pages/data were parked in a graveyard (since deleted — `592dff5`
   has them), the `i18n` block left
   `astro.config.mjs`, and the i18n tooling retired itself ([[subsystems/scripts]]).
2. **2026-07-18** — the surviving helper layer was deleted too (`src/js/localeUtils.ts`,
   `src/js/translationUtils.ts`, `src/config/translationData.json.ts`, `src/config/en/`): with one
   locale the helpers were pass-throughs, and the project committed to single-language.

## What replaced it

- **Config is flat and imported directly**: `src/config/siteData.json.ts` and `legalData.json.ts`
  (moved up from `config/en/`), typed by `configDataTypes.ts`. No registries, no `getTranslatedData` —
  pages `import siteData from "@config/siteData.json"`.
- **Two constants** in `src/config/siteSettings.json.ts:12-14` are the only locale facts left:
  `siteLang` (`"en"`, the `<html lang>` in `BaseLayout`) and `siteLocale` (`"en-US"`, feeding
  `formatDate`, `og:locale`, and JSON-LD `inLanguage`).
- **UI strings are inline** in their components; shared copy flows route → section as props (the 404
  title/description — [[concepts/page-composition]]).
- **`formatDate(date)`** (`src/js/textUtils.ts:32`) lost its locale parameter and formats with
  `siteLocale`.
- **No hreflang** is emitted ([[subsystems/seo]]) and content collections are flat
  (`src/data/blog/<slug>/`, [[subsystems/content-collections]]).

## Re-adding i18n

Don't re-introduce locale plumbing piecemeal — the pieces only work as a set: a `locales` list +
per-locale config/data registries + resolver/translation helpers + `src/pages/<locale>/` mirrors +
hreflang in `BaseHead` + the `astro.config.mjs` `i18n` block. Git history (pre-2026-07-18) has the
complete working shape, including the removed fr material (`git show 592dff5 --stat`).
