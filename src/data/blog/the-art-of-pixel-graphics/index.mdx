Welcome to the deep dive into the foundational structure of retro aesthetics. The 8-pixel block is
not merely a constraint; it is a philosophy of design that forces intentionality in every single dot
plotted to the screen.

## The Art of Dithering

When you lack the color depth to create smooth gradients, you must trick the human eye. Dithering
achieves this by alternating pixels in a checkerboard pattern.

- **Performance:** Reduces memory overhead significantly.
- **Texture:** Provides a gritty, tactile feel to otherwise flat surfaces.
- **Banding Prevention:** Eliminates the harsh steps found in low-color gradient attempts.

> The grid is the ultimate truth. It demands perfection, allowing no room for half-measures or
> blurred edges.

Below is an example of a simple rendering loop demonstrating spatial awareness within the fixed
resolution buffer.

```c
void render_grid(uint8_t* buffer) {
  for (int y = 0; y < SCREEN_H; y++) {
    for (int x = 0; x < SCREEN_W; x++) {
      if ((x % 8 == 0) || (y % 8 == 0)) {
        buffer[y * SCREEN_W + x] = COLOR_GRID;
      } else {
        buffer[y * SCREEN_W + x] = COLOR_BG;
      }
    }
  }
}
```
