You can run a thoroughly modern pipeline while keeping the aesthetic firmly in 1995 — green phosphor,
ASCII banners, and all.

## The Pipeline

Under the retro veneer it is boringly current: commits trigger a build, tests gate the merge, and a
green deploy promotes to production. What we changed is the _feel_ — every log line prints in a
monospace terminal palette, and a successful ship renders an ANSI victory screen.

- **Immutable artifacts:** every build is a versioned, reproducible bundle.
- **Fast rollback:** the previous release is one command away.
- **Loud feedback:** the terminal cheers when the deploy is green.

Nostalgia is a UI layer. The engineering underneath stays honest.
