This dashboard is the single pane of glass for a high-concurrency API. A Go collector fans out
Prometheus scrapes, a rule engine turns plain-language thresholds into alerting expressions, and a
React front end renders the whole system state on a retro grid. Trace drill-down ties every latency
spike back to the request that caused it. _(In active development.)_
